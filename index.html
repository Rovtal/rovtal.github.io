Tool #1: ubl-invoice-audit v0.1.0

An open-source in-memory auditing core for nested .zip and .xml UBL-TR invoice archives from Turkish Revenue Administration (GIB) portals, hardened against XML external entities (XXE) and path traversal (zip-slip).

  • Exact Decimal line-total, multi-rate VAT, and WithholdingTaxTotal verification with zero floating-point rounding drift
  • Detects duplicate ETTN (UUID) records, repeated supplier invoice numbers, and same supplier + date + amount probable duplicates
  • Supports both corporate PartyName (VKN) entities and sole-proprietor Person (TCKN) schemas
  • Includes --fail-on-error flag returning exit code 2 plus JSON summary output for automated batch pipelines 
ubl-audit audit .\faturalar .\arsiv.zip -o .\denetim_raporu.xlsx --fail-on-error

Tool #2: excel-merge-audit v0.1.0

An open-source offline engine that consolidates heterogeneous .xlsx, .csv, and .tsv tables without requiring openpyxl or pandas, aligning bilingual column schemas and auditing decimal totals.

  • Auto-detects UTF-8, cp1254 (Windows-1254), and ISO-8859-9 encodings with ; / , / TAB delimiters
  • Skips top report banner rows, prevents sparse OpenXML empty-cell column shifting, and normalizes Excel serial dates to YYYY-MM-DD
  • Separates exact duplicates, flags conflicting same-document rows with different amounts, and strips repeated GENEL TOPLAM summary rows
  • Hardened against XXE, zip-slip, and spreadsheet formula injection (CWE-1236) 
excel-merge merge .\dosyalar -o .\birlesik_rapor.xlsx --json .\ozet.json --fail-on-error

Workflow and Delivery Principles

Unlike rigid cloud SaaS subscriptions, every utility is built to match your existing accounting layout and stays fully under your control.

Build First, Verify Live
A working tool is assembled locally against 3–5 anonymized sample files or spreadsheet templates before delivery, so expected output is verified directly.
Strict Local Data Privacy
No XML invoice, ledger extract, or business spreadsheet is uploaded to third-party APIs or external clouds; parsing and reconciliation run offline on local Python runtimes.
Accounting-Ready Output
End users never deal with raw scripts or JSON logs; output ships as formula-driven, filterable .xlsx workbooks aligned with Logo, Zirve, or internal reporting layouts.
Test-Verified Delivery
Every published repository ships with unit tests covering malformed encodings, decimal rounding, and security edge cases.
